## Run a template

Unzip it and open `source/`. With Node.js 22.13 or newer:

```sh
npm run install:ci
npm run dev
```

`npm run build` makes a production build. These are vinext/Vite React apps with a Cloudflare Worker entry, not
standalone HTML. Forms, purchases, booking and search are visual only until you connect your own services.

## Assets

Free to download and use. Existing third-party font and asset notices still apply; see `FREE-DOWNLOAD-NOTES.md`
and each template's `ASSET-NOTES.md`. Reference images and links named in the prompts explain the build and are not
licensed stock.
